# Hushwell builds

Downloads for Hushwell's Mac app and Chrome extension. Each release has:

- `Hushwell-<version>-<build>-arm64.dmg` and `.zip`: Mac with Apple silicon (M1 and later)
- `Hushwell-<version>-<build>-x86_64.dmg` and `.zip`: Mac with an Intel processor
- `hushwell-chrome-<version>.zip`: the Chrome extension
- `SHA256SUMS`: the files' checksums

## Install on a Mac

1. Open the `.dmg` and drag Hushwell into Applications.
2. Open Hushwell. macOS says it can't check it for malicious software: choose **Done**.
3. In **System Settings › Privacy & Security**, choose **Open Anyway** next to Hushwell, then confirm.

After that, Hushwell updates itself from here.

The source lives in a private repository. This one only holds what it builds.
